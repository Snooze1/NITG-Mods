All mods available as of NotITG v4.2.0

All # are ints, example:
spline#rotx# can be spline1rotx3
bumpy# can be bumpy2

All % are floats, example:
%x can be 1.5x
diffuse|%|%|% can be diffuse|0.2|0.5|0.9

It is also possible to pass in the name of a noteskin to set it,
example: metal
